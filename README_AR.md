# بوكر سوريا VIP — نسخة تطوير أولية

هذا المشروع لعبة جديدة مستقلة مستوحاة من نمط ألعاب البوكر الاجتماعي، وليست نسخة من كود أو ملفات اللعبة الأصلية.

## الموجود في النسخة
- واجهة عربية وهوية خضراء/ذهبية.
- لوبي رئيسي وغرف لعب.
- طاولة 6 لاعبين تجريبية.
- ملف شخصي ومتجر.
- شاشة مكافآت محلية تجريبية.
- مكافأة تسجيل Facebook تجريبية بقيمة 10,000,000.
- مكافأة فيديو تجريبية بقيمة 10,000,000 لكل مشاهدة محاكاة.
- أي ربط حقيقي مع Facebook أو إعلانات يجب إضافته لاحقاً عبر SDK رسمي وخادم تحقق.

## البناء
يتطلب Android SDK وGradle/Android Studio. المشروع حالياً مصدر Android Java.

## ملاحظة
لا يتضمن هذا المشروع تجاوزاً أو تعديلًا لنظام مكافآت لعبة طرف ثالث، ولا يستخدم أصولها المحمية.
